# NH_Futures-pioneers
NH 선물 REST API Pioneers 1기 Lead-Lag 팀 활동 저장소


## 팀 소개
NH선물 REST API를 활용해 시세 조회와 모의환경 실습을 진행합니다.

## 주차별 활동
| 주차 | 활동 |
|---|---|
| 1주차 | API 키 발급, 첫 API 호출 확인, 팀 저장소 준비 |
| 2주차 | 국내 선물 투자전략 - 볼린저 평균회귀 |
| 3주차 | 해외 선물 투자전략 - ATR 추세추종 |
| 4주차 | 스프레드전략 - 삼성전자 하이닉스 스프레드 페어 전략 |
| 5주차 | 데이터기반 투자 - 병목어에 대한 2차 공급원 투자 전략 |

## 보안 원칙
- 인증정보와 개인정보는 저장소에 올리지 않습니다.
- 실제 설정 파일은 `.gitignore`로 제외하고, 값이 비어 있는 템플릿만 공유합니다.
- 주문 실습은 모의환경에서 진행합니다.
